System icons: Dot-art by Yoshi-kun

GB, GBC, GBA, NES, SNES, MD, PS1, GG, SMS, NGP, PICO8, 32X, SEGACD, PCE and PCECD are from
OnionUI's Dot-art by Yoshi-kun set, ported by Cindy Nemi and Aemiii91:
https://github.com/OnionUI/Themes/tree/main/icons/Dot-art%20by%20Yoshi-kun

NEOGEO is also from the OnionUI set.

N64.png, WS.png and LYNX.png are lossless PNG conversions of N64.ico,
WonderSwan_01.ico and Lynx.ico in Yoshi's original
Television game icons Ver2.97 (y_tvgame297.zip, December 14, 2010).
Original source: http://yspixel.jpn.org/icon/game/
The original Japanese readme is in System/licenses/yoshi-tvgame-readme.txt.

Onion's readme credits missing icons to faustbear's Pixel Art Icon Pack:
https://www.reddit.com/r/miniSNESmods/comments/995ylx/additional_pixel_art_icon_pack_22/

Names match Slot's system directory names. Transparent PNGs are read once
at startup. Only transparent padding is removed; scaling uses nearest
pixels. Wallpapers remain in Slot/Wallpapers and use the shelf's loader.
