Dreamcast — experimental
========================

Dreamcast support is an optional standalone Flycast launcher, not bundled
with the card. Use brick/setup-dreamcast.py on a computer to install
the pinned, verified Flycast release under Slot/System/Flycast.

Your BIOS goes in Slot/BIOS/DC/dc_boot.bin (2 MiB).
Your game images go in Slot/Games/DC (CHD, GDI, CDI, CUE, M3U).
Use HOME -> System -> System Setup to check required files.

For controls, per-game FPS, saves and troubleshooting read
docs/DREAMCAST.md in the Slot-Brick source repository.
Dreamcast performance under stock Brick firmware is unverified.
