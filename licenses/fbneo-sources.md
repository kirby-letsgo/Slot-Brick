# FinalBurn Neo (Neo Geo subset)

Distributed as the separate `fbneo_neogeo_libretro.so` library. No commercial
BIOS or game ROMs are included. FBNeo has non-commercial terms; see the verbatim
`fbneo-LICENSE.txt` and accompanying component notices.

Exact upstream source:
https://github.com/libretro/FBNeo/tree/32958a89abd645ed20387c8d31d21ede3bc48161

Archive: https://github.com/libretro/FBNeo/archive/32958a89abd645ed20387c8d31d21ede3bc48161.tar.gz
SHA-256: `29fafcf396b1ef0bf6d3d867f436cac3b50faef613bc0041619c71b2bad660f3`

Slot's changes are published in `brick/fbneo-slot.patch`: bounded directory
copies, failed loads returned to Slot rather than the FBNeo error GUI, and
load-error details written to stderr (captured by Slot's log). The changed
source is marked with the change date. The build recipe is
`brick/build-fbneo.sh` in https://github.com/kirby-letsgo/Slot-Brick .
Build with `sh brick/docker-build.sh`, or `sh brick/build-fbneo.sh host` for a
native simulator core. The Neo Geo driver table is generated before compilation;
Musashi and the Z80 interpreter are used. ZIP/7z support is enabled. CHD support
is compiled to satisfy the upstream shared CD code, but Slot exposes only the
Neo Geo cartridge system here.

The title catalogue in `crates/slot-store/src/neogeo-titles.tsv` comes from this
same pinned driver source. Regenerate with `brick/make-neogeo-titles.py`.
Original test chips are generated by `brick/sim/make-neogeo.py` and are never
packaged on the release card.
